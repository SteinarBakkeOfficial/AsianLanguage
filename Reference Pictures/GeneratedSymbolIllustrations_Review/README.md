# Generated Symbol Illustrations — Review Set

This folder contains 11 review-only educational reconstruction concepts for the current pilot symbols. They are not wired into the app and are not historical evidence.

Each image was generated with the corresponding source-backed early oracle-bone reference as a structural guide and the approved AppShell visual reference as a style guide. The intended question is whether the natural subject makes the early pictographic structure easier to understand.
