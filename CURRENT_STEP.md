### Recommended release posture

- Treat early V1 as a small, coherent museum-quality release with strong content and visual consistency, rather than a large feature-complete catalog with placeholder art.
- Keep the Symbol Journey, the historical-to-modern connection, and cross-language recognition as the release test. Every screen, collection, and illustration should reinforce that promise.
- Use the current 11 records as a design/content pilot, not as evidence that the final corpus model or collection taxonomy is complete.
- Set the V1 boundary at 100–200 symbols, but leave the final count open until the candidate bank clears historical, language, usage, visual-teaching, and asset-quality review. The release count should be the number that genuinely passes, not a quota.

### Artwork direction and decision needed

- Historical glyphs remain a separate evidence class: source-backed or licensed before runtime bundling, and never generated as historical substitutes. The current 126-character ZDIC package is local research material, not a bundled app asset.
- Educational origin illustrations and editorial collection covers may use internally authored or AI-assisted artwork, but each needs a specific visual brief, a defined role, consistent composition, and provenance/review metadata.

- The collection-cover problem is also structural: the prototype currently derives a cover from the first available origin asset in the collection. Because Pictographs and Dramatic Changes use the corpus-wide list beginning with Fire, both can display Fire art. Final collections need explicit cover assignments or a deliberate generated editorial-cover model.
- Before implementation, approve one collection-art direction against the ChatGPT visual reference: restrained editorial still life, symbolic object composition, or another explicitly chosen system. Each collection needs its own image concept; a symbol illustration should not automatically become a collection cover.

### Shared-language and formation rule — discussion

The corpus should use shared historical inheritance and four-track relevance as eligibility gates, then use teaching value to rank the survivors. A character does not need to be a pure pictograph, but it must belong to the shared inherited Han-character tradition and be present as a recognized Japanese Kanji and Korean Hanja, with meaningful contemporary relevance in the Chinese tracks. If it is absent from either Kanji or Hanja, it is disqualified regardless of teaching potential. Later regional glyph standards can still represent an older shared character identity; later local character creations without a shared ancestor should be excluded.

There is no single precise “language split” date to apply mechanically. The next audit should therefore record historical provenance, earliest verified stage, formation type, current Kanji/Hanja inventory membership, and modern evidence in each track. A differing Japanese or Korean form is acceptable when it represents the same inherited character identity; a later local character identity is not. Korean relevance must be labeled honestly as Hanja recognition, compounds, names, formal vocabulary, or cultural context where it is not ordinary Hangul spelling.

Working taxonomy thought for discussion, not a decision: semantic collections could carry the main discovery experience (for example Nature, People/Body, Animals, Sky/Time, Materials/Objects, Place/Movement, and Society), while Pictographs, Components, and Dramatic Changes may work better as curated lenses or filters than as peer collections. A reasonable exploration range is roughly six to ten strong editorial collections for a 100–200 symbol V1; the count should follow coherent coverage and artwork quality, not a quota.
